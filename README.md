# Quran Mechanical Top 100 (Pure 18‑Letter Mechanica)

Dit project bevat een volledige mechanische ontleding van de 100 meest
voorkomende Qur'an‑woorden, gebaseerd op **exact 18 letters** uit de dataset
"Harflrin-Anlami-Hafif.txt".

Er wordt uitsluitend gewerkt met:
- de 18 letterfuncties uit de dataset (geen toevoegingen)
- pure mechanische kettingen (letter → functie)
- geen grammatica, geen interpretatie, geen semantiek

De top‑100 is volledig **herberekend** volgens deze strikte mechanische regels.

---

## 18 Letters (Gestandaardiseerde Kernfuncties)

Elke letter heeft precies **één kernfunctie**, rechtstreeks uit de dataset:

- ن — verborgen  
- ي — omgekeerd  
- ل — voortgang  
- ح — output  
- ه — toestemming  
- د — data  
- و — zien  
- ق — gedachte  
- ك — voor‑zichzelf  
- ع — intellect  
- ص — zijde  
- س — vraag  
- ب — willen  
- ا — het  
- ف — feiten  
- م — vasthouden  
- ط — druk  
- ر — kijken  

Deze 18 vormen de **mechanische basis** van alle woordontledingen.

## Mechanische Methode

1. Een woord wordt opgesplitst in individuele letters.  
2. Elke letter wordt vervangen door zijn **kernfunctie**.  
3. De functies worden in volgorde gecombineerd tot een **mechanische ketting**.  
4. De ketting vormt de mechanische betekenis van het woord.  
5. NL / EN / TR worden toegevoegd voor praktische leesbaarheid.

Voorbeeld:

**علم**  
- ع = intellect  
- ل = voortgang  
- م = vasthouden  

→ **intellect → voortgang → vasthouden**  
→ NL: weten · EN: know · TR: bilmek
