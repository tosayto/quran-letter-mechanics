# Quran Mechanical Top 100 Words
Dit project bevat een mechanische ontleding van de 100 meest gebruikte woorden
in de Qur'an, gebaseerd op letter-mechanica uit het document
"Harflrin-Anlami-Hafif.txt".

## Doel
De Qur'an wordt begrijpelijk wanneer woorden worden gelezen als mechanische
combinaties van letters. Elke letter heeft een vaste functie (NL/EN/TR).
Door deze functies te combineren ontstaat een transparante betekenis die
controleerbaar is zonder interpretatie.

## Methode
1. Elk woord wordt opgesplitst in letters.
2. Per letter wordt de mechanische functie opgehaald uit jouw document.
3. De functies worden gecombineerd in volgorde.
4. De combinatie vormt de mechanische betekenis van het woord.

Voorbeeld:
علم = ع + ل + م  
= intellect → voortgang → vasthouden  
= weten / to know / bilmek

Alle 100 woorden zijn volgens deze methode verwerkt.
